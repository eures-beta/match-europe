# Skills du projet

Procédures à lire selon le travail, en complément du fichier AGENTS racine.

- [django-change/](django-change/) : changement de code, service ou modèle Django.
- [interface-change/](interface-change/) : interface, gettext, accessibilité et marque.
- [stack-maintenance/](stack-maintenance/) : revue, rafraîchissement et fusion autorisée.
- [pull-request-opening/](pull-request-opening/) : ouverture, template actuel,
  aperçus visuels et contrôle de la pile avant et après création.

Les descriptions servent à sélectionner les skills ; les détails sont lus à la demande.
