Commencer par [la vue d’ensemble](VUE_ENSEMBLE.md), puis [les décisions](DECISIONS.md). Les autres documents expliquent les parcours, leurs limites et les choix techniques. Ces documents détaillent le code ; ils ne prouvent pas à eux seuls l’état d’un environnement déployé.
