# Configuration du projet Django

Ce dossier contient la configuration unique du site : `settings.py` pour les réglages, `urls.py` pour les routes, `wsgi.py` et `asgi.py` pour les serveurs. `health.py` porte la sonde de santé ; les fichiers `test_*.py` vérifient notamment le démarrage et les modes de fonctionnement. Le code métier se trouve dans [eures_beta](../eures_beta/README.md). Le seul `manage.py` est à la racine du dépôt.
