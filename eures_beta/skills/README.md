# Compétences partagées

Cette application porte les catalogues ESCO de compétences, les suggestions par métier et le composant commun aux formulaires candidat et employeur. Les réponses personnelles restent dans ces applications métier.

- [data/](data/) : sélections et sources officielles.
- [models.py](models.py) : suggestions communes versionnées.
- [migrations/](migrations/) : transfert du modèle sans déplacement de sa table.
- [tests/](tests/) : services, formulaires intégrés et conservation des données.
- [../occupations/](../occupations/) : référentiels et recherche des métiers.
