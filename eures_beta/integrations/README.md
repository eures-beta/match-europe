# Intégrations externes partagées

Clients techniques réutilisables, sans logique employeur ou candidat.
`albert.py` gère le HTTP, l’authentification, les bornes et les erreurs sûres.
Les prompts, schémas et validations métier restent dans les applications concernées.
Les secrets viennent des réglages Django ; aucune valeur n’est versionnée ici.
