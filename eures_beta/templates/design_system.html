Couleurs : rôles

Les pages et les composants utilisent ces tokens. Le contraste est mesuré sur fond blanc, arrondi vers le bas. Exception : les textes prévus pour un fond coloré (blanc sur bleu, foncé sur jaune) sont mesurés sur ce fond. WCAG AA : 4,5:1 pour un texte, 3:1 pour un grand texte, une icône ou une bordure de champ.

Alertes

Le message reste en texte foncé : le vert et l’orange de l’ECL ne sont pas lisibles en texte. Le statut est dit en toutes lettres, pas seulement par la couleur.

Succès : l’offre est publiée.
Information : la recherche de candidats démarre après la validation d’un conseiller.
Attention : trois champs ont été pré-remplis automatiquement. Vérifiez-les.
Erreur : l’offre n’a pas pu être enregistrée. Réessayez dans un instant.
