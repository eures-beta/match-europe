# Templates de l’administration

Ces surcharges ciblées prolongent les templates Django standards.

- [change_list.html](change_list.html) — Ajoute le bouton de masquage du panneau de filtres aux listes concernées.
- [index.html](index.html) — Propose les nombres d’enregistrements à la demande sur l’accueil de consultation et retire les messages historiques potentiellement sensibles.
- [read_only_change_form.html](read_only_change_form.html) — Présente les objets en lecture seule.
- [README.md](README.md) — Présente les surcharges de ce dossier.
- [base_site.html](base_site.html) — Conserve le bandeau de test et le changement de compte dans l’administration.
