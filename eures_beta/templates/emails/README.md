# Présentation e-mail commune

- `message.html` : alternative HTML du texte transactionnel, avec liens explicites.
- `link_fallback.html` : adresse complète à copier dans les invitations riches.

Le texte métier et gettext restent partagés ; aucun script ni ressource externe
n'est nécessaire pour activer un lien. Voir le [rendu](../../emails/) et
[l'étude de compatibilité](../../../docs/EMAIL_LINKS.md).
