# Pages et fragments employeur

`landing.html`, `import.html`, `import-v2.html` et `privacy.html` portent les pages du parcours employeur. D’autres fichiers sont des fragments inclus par ces pages : étapes de relecture, notices et textes traduits pour les widgets. `push-test.html` sert au diagnostic Push. Un fichier HTML ici n’est donc pas nécessairement une route autonome. Voir [les traductions employeur](../../../docs/EMPLOYER_TRANSLATIONS.md).

## Contenu de ce dossier

### Fichiers

- [condition_strings.html](condition_strings.html) — Template Django pour textes traduits des conditions de travail.
- [development_notice.html](development_notice.html) — Template Django pour notice de développement du parcours employeur.
- [import-v2.html](import-v2.html) — Template Django pour variante V2 du parcours d’import employeur.
- [import.html](import.html) — Template Django pour import et relecture de l’offre employeur.
- [landing.html](landing.html) — Template Django pour accueil du parcours.
- [language_strings.html](language_strings.html) — Template Django pour textes traduits du choix de langues.
- [occupation_strings.html](occupation_strings.html) — Template Django pour textes traduits du sélecteur de métiers.
- [privacy.html](privacy.html) — Template Django pour notice de confidentialité employeur.
- [push-test.html](push-test.html) — Template Django pour diagnostic Push.
- [README.md](README.md) — Présente ce dossier et guide la lecture de son contenu.
- [review_steps.html](review_steps.html) — Template Django pour étapes de relecture de l’offre.
