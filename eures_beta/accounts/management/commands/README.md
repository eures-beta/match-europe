# Initialisation des comptes fictifs

`seed_demo.py` initialise le scénario et les acteurs fictifs. Ce n’est pas une procédure de création de vrais comptes utilisateurs. Pour un essai local, la cible `make seed-demo`, lancée depuis la racine, utilise la base choisie dans votre configuration locale. Lire sa recette dans le [Makefile](../../../../Makefile) avant de l’exécuter.

## Contenu de ce dossier

### Fichiers

- [__init__.py](__init__.py) — Identifie ce dossier comme un paquet Python.
- [README.md](README.md) — Présente ce dossier et guide la lecture de son contenu.
- [seed_demo.py](seed_demo.py) — Initialise les acteurs et objets fictifs du scénario de démonstration.
