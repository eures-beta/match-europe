# Catalogue gettext — français

`django.po` est le catalogue lisible et modifiable : chaque texte source y est associé à sa traduction. `django.mo` est sa version compilée, utilisée à l’exécution. Après modification, lancer `make translations-check` et `make translations-compile` depuis la racine. Ne pas modifier le fichier binaire `.mo` à la main.

## Contenu de ce dossier

### Fichiers

- [django.mo](django.mo) — Catalogue gettext compilé utilisé par Django à l’exécution.
- [django.po](django.po) — Catalogue gettext lisible contenant les traductions de cette langue.
