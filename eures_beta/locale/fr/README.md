# Traductions en français

Ce dossier regroupe les catalogues gettext pour le français. Le code de langue `fr` sélectionne ces traductions ; les textes sources restent dans le code et les templates, sans copie HTML par langue.

## Contenu de ce dossier

### Dossiers

- [LC_MESSAGES/](LC_MESSAGES/) — `django.po` est le catalogue lisible et modifiable : chaque texte source y est associé à sa traduction.

### Fichiers

- [README.md](README.md) — Présente ce dossier et guide la lecture de son contenu.
