# Accueil candidat

`landing.html` est le template unique de l’accueil candidat en français, anglais et allemand, via gettext. Les trois choix affichés sont encore simulés : leur présence ne signifie pas qu’un parcours CV ou LinkedIn complet est raccordé. Voir [le périmètre de cette page](../../../../docs/CANDIDATE_LANDING.md).
