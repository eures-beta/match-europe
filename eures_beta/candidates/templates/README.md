# Templates propres aux candidats

Ce dossier rassemble les templates appartenant à l’application candidats. Le sous-dossier `candidates/` sert d’espace de noms pour que Django distingue ces templates de ceux des autres applications. Le cadre HTML commun reste dans [les templates partagés](../../templates/).

## Contenu de ce dossier

### Dossiers

- [candidates/](candidates/) — `landing.html` est le template unique de l’accueil candidat en français, anglais et allemand, via gettext.
