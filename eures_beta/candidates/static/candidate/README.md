# Styles et interactions de l’accueil candidat

`candidate.css` définit la présentation de l’accueil et `candidate.js` ses interactions de sélection. Ils accompagnent [le template candidat](../../templates/candidates/). Ces interactions de maquette ne créent pas à elles seules un profil ni un import CV.

## Contenu de ce dossier

### Fichiers

- [candidate.css](candidate.css) — Feuille de styles pour présentation ou interactions de l’accueil candidat.
- [candidate.js](candidate.js) — JavaScript pour présentation ou interactions de l’accueil candidat.
- [README.md](README.md) — Présente ce dossier et guide la lecture de son contenu.
