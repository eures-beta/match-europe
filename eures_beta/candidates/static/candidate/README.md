# Styles et interactions de l’accueil candidat

`candidate.css` définit la présentation de l’accueil et `candidate.js` ses interactions de sélection. Ils accompagnent [le template candidat](../../templates/candidates/README.md). Ces interactions de maquette ne créent pas à elles seules un profil ni un import CV.
