# Migrations — offers

Ces fichiers décrivent l’évolution du schéma et de l’état Django pour les offres et questions. Ils sont versionnés pour reproduire la même évolution sur chaque base. Les migrations initiales participent au transfert depuis l’historique `journeys` ; elles ne signifient pas nécessairement une nouvelle table physique. Depuis la racine, `make migrations` affiche leur état et `make check` détecte les changements de modèles sans migration. Voir [la compatibilité des données](../../../docs/DOMAIN_EXTRACTION.md).
