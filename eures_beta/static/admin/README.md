# Présentation de l’administration

Ces ressources complètent Django Admin sans modifier ses permissions.

- [filter-toggle.js](filter-toggle.js) — Affiche ou masque le panneau de filtres et mémorise uniquement ce choix dans le navigateur.
- [filter-toggle.css](filter-toggle.css) — Libère la largeur du panneau lorsqu’il est explicitement masqué.
- [README.md](README.md) — Présente les ressources de ce dossier.
