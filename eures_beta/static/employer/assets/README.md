# Images de l’interface employeur

Ce dossier conserve les images et logos utilisés par les pages, dont les marques des partenaires et Match Europe. Ce sont des ressources visuelles, pas des templates ni des données métier. Leur emplacement historique sous `employer/` n’empêche pas le bandeau commun de réutiliser une image sur d’autres pages.
