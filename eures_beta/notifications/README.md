# Notifications dans le site

Cette application enregistre les notifications destinées aux utilisateurs et permet de les consulter ou de les marquer comme lues. Une notification en base n’est pas à elle seule une notification Push livrée par le navigateur. Le diagnostic Push est un sujet distinct, porté actuellement par le [code employeur](../employers/README.md).
